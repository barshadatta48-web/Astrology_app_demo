# AstroVerse — Cosmic Edition

A cosmic-themed React + Vite Vedic astrology demo, prepared for Vercel.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Demo access
- Username: `owner`
- Password: `Cosmic@2026`

This is a front-end demonstration login, not production-grade authentication. Do not use it to protect private data. Replace it with a server-verified authentication provider before public production use.

## Demo astrology data
Kundli placements, Panchang values, planetary positions, and horoscope text are illustrative demo content. They are not calculated from an ephemeris and should not be used for real astrological decisions.

## Deploy to Vercel
Import this repository into Vercel. Framework preset: **Vite**. Build command: `npm run build`. Output directory: `dist`. No environment variables are required for this demo.
